把视频和声音，留在本地

视频和声音，留在本地。

点「下载视频」或「下载 MP3」，可以直接在 Chrome 内保存。需要大文件、BT 或让任务在关闭浏览器后继续时，可以安装配套桌面版，再在设置（面板右上角的齿轮）里选择「交给桌面版」。

桌面版完整安装方法与连接检查 · 网站权限

第一次装好，之后直接下载

  1. 把 Ruxget 固定到工具栏点 Chrome 右上角的拼图图标，再点 Ruxget 旁边的图钉，之后一键即可打开。面板右上角的齿轮用于打开设置。
  2. 打开 B站、抖音、快手或小红书视频点击 Ruxget，标题与清晰度自动读取。B站也可以粘贴网址后点「读取」。抖音和小红书第一次下载时，Chrome 会问一次是否允许访问它们的视频服务器。
  3. 选择保存方式直接点「下载视频」保存带声音的 MP4，或点「下载 MP3」单独保存声音。已装桌面版的用户，可以在设置（右上角的齿轮）里选择哪些下载交给桌面版，交过去会直接开始。

文件在哪里？

在设置（面板右上角的齿轮）的「保存位置」中，可以开启「每次保存时选择文件夹」。开启后，新下载的文件准备好时会打开 Chrome 原生保存窗口，可选择文件夹和文件名；未开启时保存在 Chrome 默认下载目录的「Ruxget」子文件夹。点同一处的「更改 Chrome 下载文件夹」可更改默认目录。桌面主界面底部点「选择文件夹…」可更改新任务默认目录，也可在新建或批量下载确认框点「选文件夹」指定本次位置。已有任务保留原位置；开启按类型归档时会创建子文件夹。

B站等平台的视频开始用插件下载后，可以关掉插件面板和进度页，请保持 Chrome 运行。其他网站打开“视频下载”页（HLS / DASH）的下载在那个页面里进行，下载完成前请保持它打开，关闭或刷新会中断下载。交给桌面版的任务可以在关闭浏览器后继续，请保持桌面版运行。

移动或隐藏下载浮钮

点击视频旁的小「Ruxget 下载」按钮，就地展开清晰度和 MP3 选项；再点一下、点击空白处或按 Esc 收起。选择下载后自动缩成小进度入口，下载详情只在主动点击时打开。按住浮钮文字可拖动，刷新后记住位置。在就地菜单点「隐藏浮钮」，或在设置的「网页上」关闭「在视频网页上显示下载浮钮」，都能隐藏网页按钮。需要时在设置里重新打开即可。显示或隐藏状态会记住，不会自动占用侧栏。

清晰度与其他网站

只显示原站实际提供的清晰度。B站更高清的画面可能需要先在原站登录。其他网页可以播放视频后，尝试下载列表里发现的媒体；各网站的格式和访问权限会影响结果。部分网站插件无法读取；需要更多网站、大文件或 BT 时，可以使用 Ruxget 桌面版。

普通文件：Chrome 或 Ruxget，自由选择

平时左键点击网页下载，默认仍由 Chrome 处理。想让桌面版接管，在“桌面版安装与连接”页打开「用 Ruxget 接管 Chrome 下载」：之后网页上的普通下载会直接交给桌面版，可以暂停续传。桌面版没开、文件很小、网站在“不接管”名单里，或链接需要网页登录时，照常由 Chrome 下载。也可以右键 HTTP / HTTPS 下载链接，选择“用 Ruxget 桌面版下载此链接”，或在 Ruxget 面板里点“普通文件下载…”。

Ruxget 不读取剪贴板。交给桌面版时只转交链接、来源页和浏览器标识，不读取或导出 Cookie、Authorization 请求头或表单内容。网页生成的 blob 临时文件、表单下载和需要登录状态的文件，继续由 Chrome 下载。网盘下载是例外：你在某个网盘开启“Ruxget 下载”时 Chrome 会询问，允许后 Ruxget 只把这个网盘的登录信息连同文件交给本机桌面版，不发往别处。桌面版未连接时，按“桌面版安装与连接”操作即可。

版本、适用范围与许可

中文、免费、无广告。随插件提供的开源组件（hls.js、mux.js、mpd-parser、MP4Box.js、lamejs）保留各自的许可声明。直接下载由 Chrome 处理，交给桌面版的任务由本机软件处理。

插件需要 Chrome 116 或更新版本，桌面版适用于 Windows 10/11 64 位电脑。优先支持公开、非直播视频。浏览器内下载的单个媒体轨最大 768 MB，过大时可选择更低清晰度或使用桌面版。不提供 DRM 绕过。普通网页的旧分段下载仍需保持其下载页面打开。高级工具的可选外部转换只有主动使用时才连接。
