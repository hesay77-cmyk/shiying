把视频和声音，留在本地

视频和声音，留在本地。

点「下载视频」或「下载 MP3」，可以直接在 Chrome 内保存。需要大文件、BT 或让任务在关闭浏览器后继续时，可以安装配套桌面版，再点「交给桌面版下载」。

桌面版完整安装方法与连接检查

第一次装好，之后直接下载

  1. 把Ruxget放到 Chrome 里商店正式版在原商店条目安装或更新；当前本地预览版需要解压插件包，在扩展管理页加载「Chrome插件」目录。查看完整插件安装方法。
  2. 打开 B站或 YouTube 视频点击Ruxget，标题与清晰度自动读取。也可以粘贴网址后点「读取」。
  3. 选择保存方式直接点「下载视频」保存带声音的 MP4，或点「下载 MP3」单独保存声音。已装桌面版的用户，也可以点「交给桌面版下载」，在桌面窗口确认保存位置。

文件在哪里？

插件的网页下载选项和工具栏小弹窗都有「保存时选择文件夹」。勾选后，新下载的文件准备好时会打开 Chrome 原生保存窗口，可选择文件夹和文件名；未勾选时保存在 Chrome 默认下载目录的「Ruxget」子文件夹。「默认位置…」可打开 Chrome 下载设置，更改默认目录。桌面主界面底部点「选择文件夹…」可更改新任务默认目录，也可在新建或批量下载确认框点「选文件夹」指定本次位置。已有任务保留原位置；开启按类型归档时会创建子文件夹。

插件下载期间可以关掉插件小窗口和进度页，请保持 Chrome 运行。交给桌面版的任务可以在关闭浏览器后继续，请保持桌面版运行。

移动或隐藏下载浮钮

点击视频旁的小「Ruxget下载」按钮，就地展开清晰度和 MP3 选项；再点一下、点击空白处或按 Esc 收起。选择下载后自动缩成小进度入口，下载详情只在主动点击时打开。按住浮钮文字可拖动，刷新后记住位置。在就地菜单点「隐藏浮钮」，或用 Chrome 工具栏Ruxget弹窗右上角的「隐藏浮钮」，都能隐藏网页按钮；工具栏里的隐藏开关还会同时收起弹窗和已打开的右侧栏。需要时打开工具栏里的Ruxget，点「显示浮钮」恢复。显示或隐藏状态会记住，不会自动占用侧栏。

清晰度与其他网站

只显示原站实际提供的清晰度。B站更高清的画面可能需要先在原站登录。其他网页可以播放视频后，尝试下载列表里发现的媒体；各网站的格式和访问权限会影响结果。

普通文件：Chrome 或Ruxget，自由选择

平时左键点击网页下载，仍由 Chrome 处理；Ruxget不会拦截、暂停下载或自动打开桌面软件。需要桌面版时，右键网页中的 HTTP / HTTPS 下载链接，选择“用Ruxget下载此链接”，再在桌面版确认保存位置。也可在Ruxget工具栏菜单里打开“普通文件下载…”，粘贴链接，选择“用 Chrome 下载”或“用Ruxget下载”。取消、关闭菜单或不用此功能均不会启动下载。

不记住强制接管规则，不自动读取剪贴板，不会把所有下载交给桌面版。网页生成的 blob 临时文件、表单下载和需要登录状态的文件，继续用网页原来的 Chrome 下载方式；此入口只转交链接与来源信息，不读取或导出 Cookie、Authorization 请求头或表单内容。桌面版未连接时，按“桌面版安装与连接”操作即可。

版本、适用范围与开源信息

当前本地插件 0.4.4，配套桌面版 0.4.26，尚未作为这次更新公开发布。中文、免费、无广告。基于 CatCatch 猫抓 修改，保留原作者及第三方声明，GPL-3.0 允许使用、修改和再分发。MP4Box.js 和 lamejs 随插件提供；直接下载由 Chrome 处理，交给桌面版的任务由本机软件处理。

插件需要 Chrome 116 或更新版本，桌面版适用于 Windows 10/11 64 位电脑。优先支持公开、非直播视频。浏览器内下载的单个媒体轨最大 768 MB，过大时可选择更低清晰度或使用桌面版。不提供 DRM 绕过。普通网页的旧分段下载仍需保持其下载页面打开。高级工具的可选外部转换只有主动使用时才连接。
