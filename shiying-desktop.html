桌面版负责保存文件、暂停续传和下载大文件。只用浏览器下载时，可以不装。

正在检查桌面版…

只需要一两秒。

先安装桌面版

适用于 Windows 10 / 11（64 位）。下载后双击运行，点「安装并连接」，大约一分钟。

下载 Windows 安装包

在下载页点「下载 Windows 版」。装好后点「我已经装好了」，Chrome 会问一次是否允许连接。

差一步：连接插件

桌面版已经装好，还没和这个插件配对。点下面的按钮，浏览器询问时选「打开」，再在 Ruxget 窗口里点「是」。

一键连接

连接成功后，这里会自动进入下一步。

已连接 Ruxget 桌面版

回到视频页，点下载按钮旁的 ▾，选「用桌面版下载」。以后会记住你的选择。

    更多帮助

    没有连上，或者下载没开始

    已经安装，仍提示还没连接

    先点「一键连接」，按提示打开 Ruxget 并确认，再点「重新检查」。如果按钮打不开程序，正常关闭旧的桌面版，重新运行安装器并点「安装并连接」。

    刚才没有允许 Chrome 的连接权限

    再点一次「我已经装好了」或「重新检查」，按提示允许即可。不允许时，仍然可以用浏览器下载。

    组件一直准备失败，或任务没有速度

    先看桌面版「设置」里的代理：默认「跟随系统代理」；如果代理软件没开系统代理，改成「自定义…」填写它的地址。确认网络能访问视频来源及组件来源后，再继续或重试。BT 下载速度还取决于当前做种节点，安装成功并不保证每个种子都有速度。

    只看到几个 KB 的 MP3，或视频地址已过期

    在 Ruxget 主面板确认正片标题与清晰度，再发送到桌面版。高级资源列表里的小 MP3 可能只是网页提示音。地址过期时，在原网页重新读取视频后重新发送。

    出现多个 Ruxget 图标或重复浮钮

    打开 Chrome 扩展管理页，核对各个 Ruxget 的版本号，只保留你准备使用的版本启用，关闭旧测试版本。更新本地插件后，重新加载扩展，再刷新视频页。

    桌面版怎么用

    打开 B站视频，点 Chrome 工具栏里的 Ruxget 图标，选好画质，在下载按钮旁的 ▾ 里选「用桌面版下载」，再点下载。也可以直接把支持的链接粘贴到桌面版里。在桌面窗口确认保存位置并开始。只在本页检查连接不会下载视频。

    下载由桌面版接收后，可以关闭浏览器；请保持桌面版运行。点「迷你窗」可只保留一个小进度窗；在「···」菜单选择「收起到托盘」可隐藏窗口并继续下载，双击托盘里的 Ruxget 即可恢复。关闭 Ruxget 窗口会保存并暂停任务，下次启动后可手动继续。

    第一次下载视频时要准备什么

    普通文件、网盘和 BT 所需的基础组件随安装包提供。首次下载视频时，桌面版会按需准备视频组件并显示进度，准备完成后再下载内容，不需要手动寻找或安装组件。

    桌面版默认「跟随系统代理」：Windows 设置里开了代理就用它，没开就直连，一般不用改。只有代理软件没有设置系统代理时，才需要在桌面版「设置」里选「自定义…」并填写地址。插件和桌面版的网络设置分别生效。

    下载好的文件在哪里

    桌面版默认保存到系统「下载」目录下的「Ruxget」文件夹，主窗口底部的「新任务保存到」旁可点「选择文件夹…」更改默认目录，并自动记住；新建或批量下载确认框中的「选文件夹」只改变本次任务的位置。已有任务保留原位置。任务完成后点「打开文件夹」；双击任务可在原窗口展开大小、已下载量、剩余时间、续传和分段进度，再双击或点「收起」关闭详情；完整详情与 BT 文件列表仍可从「···」菜单打开。

    网盘怎么交给 Ruxget 下载

    把插件和桌面版都更新到最新版后，在网盘页面点 Chrome 中的 Ruxget，再点「开启 Ruxget 下载」，允许这个网盘的可选权限。原下载按钮旁会出现一个小的「Ruxget 下载」按钮。勾选文件再点击，即可使用记住的目录在后台下载，不自动弹出主窗口。按钮的小菜单可以更换目录、查看任务或隐藏；隐藏后从插件内「显示网盘按钮」恢复。百度首次可能需另点「百度授权」并在百度页面确认。无需篡改猴，原下载按钮照常使用。

    部分分享页不支持；阿里云盘需要切换到列表视图；一次最多 100 个文件。下载地址过期时，回到网盘重新点击即可。不会突破网盘自身的限速。

    还没装插件？从这里开始

    推荐从 Chrome 网上应用店安装 Ruxget，不需要开启开发者模式，以后会自动更新。下面是手动加载开发者插件包的方法：

    1. 解压开发者提供的插件包，在 Chrome 地址栏打开 chrome://extensions。
    2. 开启「开发者模式」，点击「加载已解压的扩展程序」。
    3. 选择名为「Chrome插件」的文件夹，或解压包中直接含有 manifest.json 的目录；不要选择源码 ZIP 或桌面 EXE。
    4. 在扩展列表看到 Ruxget 后，刷新视频页或网盘页。以后覆盖更新同一文件夹时，点扩展卡片上的「重新加载」，再刷新网页。不要同时启用多份 Ruxget。
    连接诊断

    只在你点击时，或打开接管后有新下载开始时发送。媒体链接、标题、选中的音视频轨和必要的来源信息会交给本机软件；Cookie 和密码不发送。临时视频链接可能过期，失败后请重新读取并发送。
