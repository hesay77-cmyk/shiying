# 拾影：Chrome 商店填写指南

适用上传包：`拾影-0.3.2-Chrome.zip`（此 GitHub Release 提供的独立公开版）。整理日期：2026-10-12。

GitHub 上的公开发布不代表已通过 Chrome 商店审核。本指南按当前代码填写，保留 YouTube、B站和 MP3 下载功能，不隐瞒功能或外部连接。商店是否接受仍取决于审核。

## 1. 上传

1. 打开 [Chrome 开发者后台](https://chrome.google.com/webstore/devconsole)。登录你的 Google 开发者账号。新账号需自行完成注册、一次性注册费和两步验证；金额以后台显示为准。
2. 点“添加新内容 / New item”，上传 **`拾影-0.3.2-Chrome.zip`**。源码 ZIP 供开源使用，不能作为商店安装包上传。
3. ZIP 根目录直接包含 `manifest.json`。如果后台说找不到文件，请检查是否多套了一层目录。
4. 包上传后依次填写“商品详情 / Store listing”“隐私权 / Privacy”“分发 / Distribution”“测试说明 / Test instructions”。字段名以你看到的后台为准。

## 3. 隐私与权限

**单一用途 / Single purpose**，复制：

```text
识别用户访问网页中的媒体资源，并按用户选择下载视频或音频，包括在 Chrome 内合并 MP4、编码 MP3，以及与媒体下载直接相关的预览、任务管理和保存设置。
```

每项权限说明，复制对应行：

| 后台显示的权限 | 说明 |
|---|---|
| activeTab | 用户点击插件图标后，临时读取当前网页中与媒体相关的信息，以发现本页视频和媒体来源；访问随页面跨站跳转或关闭而撤销，不默认读取所有网页。 |
| tabs | 获取当前视频标签页的网址和标题，定位用户选择的视频页面，展示媒体来源；必要时打开用户输入的视频页或相关任务、帮助、工具页面。 |
| webRequest | 监听用户访问网页的网络请求以发现媒体资源、识别格式与大小，并读取下载所需的来源请求头和认证信息，避免来源网站拒绝合法可访问的媒体请求。 |
| downloads | 通过 Chrome 下载管理器保存用户选择的视频和音频，监听下载完成、失败或取消，并打开已保存文件所在目录。 |
| storage | 保存媒体目录、下载状态及用户设置。媒体和任务主要在本地或会话存储；部分设置及可选外部服务配置使用 Chrome 同步存储。 |
| webNavigation | 在网页跳转或更新时维护标签页与媒体记录的对应关系，清理过期资源，并在相关工具页面就绪后发送用户选择的媒体任务。 |
| alarms | 延迟合并媒体缓存写入，清理失效标签页和临时记录，减少高频请求带来的重复写入。 |
| declarativeNetRequestWithHostAccess | 只在已获得主机权限的媒体来源上，为用户选择的下载设置原站要求的 Referer、Origin、User-Agent 或必要认证请求头；不获得对未授权主机的隐含规则权限。 |
| scripting | 在用户选择的视频网页中运行随插件打包的脚本，读取播放信息、媒体目录和相关页面内容；执行与媒体识别、预览或录制有关的本地脚本。 |
| offscreen | 通过 Chrome 隐藏页执行本地音视频下载、MP4 合并、MP3 编码和校验，使用户关闭小面板后任务仍能继续。 |
| sidePanel | 支持用户在设置中选择用侧边栏展示同一媒体下载界面，保持工具栏小面板为默认入口。 |
| contextMenus | 用户开启此选项时提供与媒体下载相关的右键入口，默认关闭。 |
| 主机权限（所有网站） | 必选主机权限仅覆盖 B站、YouTube 的页面、正常读取 API 和必要媒体 CDN。其他网站及媒体来源使用可选权限：用户主动操作后，仅按具体网站来源授权，并可撤销。可选匹配范围用于运行时发现尚未知晓的媒体服务器，不代表安装时已获得所有网站权限；运行时不一次请求全部网站访问。数据仅用于用户操作的媒体识别和下载，不用于广告、画像或出售浏览活动。 |

**远程代码 / Remote code：选择“是 / Yes”，并解释高级功能。** 当前版本保留可选的远端网页/iframe；不要笼统选择“否”并宣称没有任何远端网页逻辑。说明可复制：

```text
插件本身的脚本、MP4Box.js 和 lamejs 均随安装包提供。默认 B站/YouTube 的 MP4/MP3 下载和转换由本地隐藏页执行，不下载远端 JavaScript 到扩展中执行。

高级工具保留用户主动选择的在线转换或流式保存功能，会打开普通第三方网页，或在独立来源的 iframe 中运行其网页代码，与其交换用户选择的媒体数据。这些网页没有直接访问 chrome.* 扩展 API 的权限。预置地址包括 ffmpeg.bmmmd.com、ffmpeg.94cat.com 和 stream.bmmmd.com。相关数据交换已在隐私政策中披露；这是可选高级功能，不是默认主下载流程的依赖。
```

该声明只是如实解释现有实现，是否符合 Manifest V3 和远端逻辑规则由审核判断。审核要求调整时，需要根据具体反馈改实现。

**数据类型 / Data usage：当前版本不要选“完全不处理用户数据”。** 即使只在本机处理，也需要披露。按实际字段勾选以下类别：

| 类别 | 为什么选 |
|---|---|
| 网站内容 / Website content | 视频、音频、网页标题、相关页面信息，以及主动使用高级预览、识别或录制功能时的内容。 |
| 网络记录 / Web history | 媒体来源页面网址、媒体请求网址、相关访问记录；用于媒体识别和下载。 |
| 身份验证信息 / Authentication information | 来源请求头中可能包含 Cookie、Authorization、令牌；可选外部服务的密码或令牌。 |
| 个人身份信息 / Personally identifiable information | YouTube 访客标识，以及用户主动配置的外部服务用户名等标识信息。 |
| 用户活动 / User activity | 媒体网络请求监测、用户发起的下载任务及其状态。 |

健康、财务支付、精确位置、私人通信不是插件专门采集的功能类别。若以后新增此类处理，应更新代码说明、隐私政策和申报。网页内容本身可能含敏感信息，不能据此承诺插件永远不会接触任何敏感文字。

数据使用的三个声明，如当前代码和用途保持本指南描述，可勾选：不出售用户数据；不将用户数据用于与单一用途无关的目的；不用于确定信用状况或贷款资格。勾选前请读后台原文并确认符合你的实际运营方式。开发者邮箱、真实身份、交易者身份等账号资料使用你本人真实情况填写，本指南不代填。

## 4. 分发与测试说明

费用选“免费 / Free”。首次只想试审核时，分发可先选“不公开列出 / Unlisted”，便于审核通过后先通过链接验证；需要公开搜索时再选“公开 / Public”。国家/地区按你计划支持的范围选择，网页来源自身的区域限制仍然有效。

**提交审核时，建议取消“审核通过后自动发布”，使用延迟发布。** 这样可以先看审核结果，再决定何时正式上架。后台如提示暂存发布期限，以其提示为准。

测试说明可复制（低于后台 500 字上限）：

```text
无需拾影账号或本机下载助手。需要 Chrome 116 或更新版本。

1. 打开 https://www.youtube.com/watch?v=aqz-KE-bpKQ （需可访问 YouTube 的网络）。
2. 点击拾影图标，等待标题、时长和清晰度显示。
3. 选择清晰度，点击“下载视频”，检查下载目录“拾影”文件夹中的 MP4 有画面和声音。
4. 点击“下载 MP3”，检查保存的音频。任务页可取消下载，下载期间保持 Chrome 运行。
5. 其他网站首次使用时，点“允许此网站”，按具体网站及媒体来源授权；需要时刷新网页并播放视频。拒绝授权不会扩大访问范围。“管理网站权限”可撤销授权。

B站可在正常可播放的视频页测试相同入口。原站权限、登录状态和区域会影响结果。默认主流程在 Chrome 内处理；高级外部服务仅在用户主动使用或配置时连接，详见隐私政策。
```

当前版本没有经过 Chrome 商店审核。默认全站访问已改为固定平台必选权限及具体网站按需授权；可选范围仍需覆盖运行时发现的其他网站。YouTube 下载、可选权限范围、来源认证信息处理及高级外部网页功能，都可能成为审核关注点。通过与否以后台结果为准；不要通过隐瞒实际功能反复提交。
