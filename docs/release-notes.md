# 拾影 0.3.2

本版针对 Chrome 商店指出的“所有网站权限”收窄访问范围，保留视频、MP3 和其他网站下载。

- 安装时仅申请 B站、YouTube 页面、读取 API 及必要媒体 CDN 的固定主机权限。
- 用户点击插件后，通过 activeTab 临时读取当前页媒体信息；其他网站首次使用时，按具体网站及本页媒体来源授权。
- 可选匹配范围用于发现运行时未知媒体来源；插件运行时只申请具体网站，不一次申请全部网站访问。
- 菜单“管理网站权限”可以添加具体网址或撤销授权；撤销后停止后续捕获并清理相关媒体缓存。
- 网络请求规则仅在已授权主机上生效。MP4 合并、MP3 编码与平台解析保持不变。
- 商店测试说明已缩短到 500 字以内，权限理由和隐私说明已同步更新。

安装包：`shiying-0.3.2-chrome.zip`（本地中文文件名为“拾影-0.3.2-Chrome.zip”）。需要 Chrome 116 或更新版本。源码包和 Chrome 商店资料包均随本次发行提供。

Chrome 商店尚未提交该版本。可选权限范围、YouTube 下载及高级外部网页仍可能接受审核；本版不保证消除所有深入审核提示或一定通过。原生授权确认及商店实际提示需在用户 Chrome 中继续核对。
