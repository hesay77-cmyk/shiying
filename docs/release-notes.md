# 拾影 0.3.1

免费、开源、无广告的中文网页视频下载扩展。

- 在 B站和 YouTube 视频页自动读取标题、时长与实际清晰度。
- 保存有声音的 MP4，或单独保存 MP3。
- 默认使用 Chrome 内的媒体处理，不用安装下载助手。
- 使用白底紧凑面板，保留 Chrome 工具栏图标入口。
- 保留通用网页媒体列表和高级工具；不同网站的格式与权限会影响可用性。

需要 Chrome 116 或更新版本。平台主流程优先处理非直播视频，单个媒体轨最大 768 MB。不提供 DRM 解密，也不提供付费内容、会员或登录限制绕过。

下载 `拾影-0.3.1-Chrome.zip`，解压后在 `chrome://extensions` 打开开发者模式，选择“加载已解压的扩展程序”，加载包含 `manifest.json` 的目录。商店审核尚未完成。

本次公开发行保留既有下载代码，仅整理项目主页、独立插件标识、来源、隐私说明和发行资料。之前自用安装包中沿用的 CatCatch 公钥已从公开包移除，公开包由 Chrome 分配独立扩展标识。现有本地安装不会自动变成该独立发行版。
